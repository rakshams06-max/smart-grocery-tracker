## Description

Smart Grocery Tracker is a simple web application that helps users manage their grocery shopping expenses.

Users can add grocery items, track prices, calculate total expenses, mark items as purchased, delete items, and monitor their monthly grocery budget.
## Features
- Add grocery items
- Enter item prices
- Display grocery items
- Calculate total expenses
- Delete grocery items
- Mark items as purchased
## Setup Instructions
- Clone the repository to your local machine
- Open index.html in your web browser
## Tech Stack
- HTML, CSS, Vanilla JavaScript
